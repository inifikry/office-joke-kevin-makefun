# The Funniest Office Joke, Judged Head to Head

One short line about office life — the whole entry. `main.py` writes a single
one-line joke to `/output/entry.txt`:

> The printer jammed again on deadline day, so I printed my resignation: the only document it's ever run without a single complaint.

Setup: the office printer jams on deadline day, a pain anyone who has worked
in an office knows. Turn: instead of fighting it, the narrator prints their
resignation — and the punchline lands last: the printer runs that one document
without a single complaint, as if it were the only colleague happy to see
them go.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no input, no network, no dependencies beyond the Python 3
standard library. Entry is 1–200 UTF-8 characters, a single line.
